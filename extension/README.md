# Redes Creation — Google Review Auto-Filler Extension (v1.1)

### Extension Update / Reload Kaise Karein (10 Seconds):
Agar aapne extension pehle se load kiya hua hai:
1. Chrome browser me `chrome://extensions` kholein.
2. **"Redes Creation — Google Review Auto-Filler"** card par **↻ (Reload icon)** par click karein.
3. Ab Google Review ka tab refresh karein!

---

### Pehli Baar Install Karne Ka Tarika:
1. Google Chrome me जाएं: `chrome://extensions`
2. Top-right me **Developer mode** toggle ko **ON** karein.
3. Top-left me **"Load unpacked"** button dabayein.
4. Ye folder select karein:
   `c:\Users\dell\Desktop\Redes Creation\extension`

---

### Ab Auto-Fill Kaise Kaam Karega:
1. **Direct on Google Tab**: Google Review ka tab (StackCode Training Institute) khulte hi:
   - Review text **automatically type/fill** ho jayega!
   - **5 Stars** automatically select ho jayenge!
   - Screen ke bottom-right me ek button bhi dikhega: `⚡ Auto-Fill Review Text` (jise click karke kisi bhi waqt direct fill kar sakte hain).
2. **Extension Icon se**: Chrome toolbar me extension icon par click karke aap direct text edit kar sakte hain aur **"⚡ Auto-Fill in Open Google Tab"** daba sakte hain!
